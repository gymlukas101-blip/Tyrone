# Computer use: research report and comparison matrix (2026-11-20)

This report compares open-source computer-use projects against what Monkey already has, to decide what to adopt.

- **Method:** three research passes read each project's source at a pinned commit. Nothing was installed or executed from them.
- **What "measured" means here:**
  - Numbers marked *vendor claim* come from the project's own README.
  - Numbers marked *measured* come from Monkey's own benchmark (`tools/computer_bench/`, see [COMPUTER-USE-QUALITY.md](COMPUTER-USE-QUALITY.md)).
  - Anything else is marked unknown.
- **Monkey baseline before this work** (`monkey/automation/`):
  - A Playwright managed browser with accessibility-snapshot refs and a permission gate.
  - A deterministic course skill and a durable `TaskManager` with pause/resume/restart.
  - A browser-only Claude fallback planner.
  - A small pywinauto UIA adapter: index refs, a generic error string, a silent fallback to the real mouse, and no waits.

## What Monkey adopted, and from where

| Idea | Source | Where in Monkey |
|---|---|---|
| Identity refs (role + name + automation id), refuse ambiguous matches, re-find on every use; fall back to role + name when a numeric id was regenerated | agent-desktop `snapshots-and-refs.mdx:134-168`, `FINDINGS.md:115` | `computer/drivers/uia.py` `_live`, `refind` |
