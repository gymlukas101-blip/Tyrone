# Email to a professor / TA / advisor

The email must sound like the user, be short, and be correct. It is only a DRAFT; the user approves sending.

1. Get the facts first, asking ONE short question only if something essential is missing:
   - recipient's name, title and email: search the user's email/memory; never invent an address. If unknown, ask.
   - course (code + name), the specific request, and any date/deadline involved.
2. Read /memories/writing_style.md (and writing_examples.md if present) and match the user's greeting, sign-off and
   formality for school contacts.
3. Structure (under ~120 words):
   - Subject: specific ("DS 240: extension request for the proposal").
   - Greeting with their title (Professor/Dr. Lastname; TA by first name only if the user does that).
   - One line of context, then the ask (with the date/time you're proposing), then an offer (e.g. office hours),
     then thanks and the user's usual sign-off.
   - Extension requests: give the real reason briefly if the user gave one; never fabricate a reason.
4. Call `draft_email`. Then say who it's to and the subject in one sentence and that it's ready to review.
   Never say it was sent unless the system confirms the user sent it.

Don't: be groveling or overly formal, add emojis, make promises the user didn't make, or CC anyone not asked for.
